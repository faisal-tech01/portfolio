📸 Overview
This is my personal portfolio website — designed and coded entirely from scratch to represent who I am as a developer and as a person. The goal was simple: build something that feels human, not templated.
It features five fully navigable pages, a particle canvas background, animated skill bars, a typewriter effect, and a responsive layout that works on every screen size.
🗂️ Project Structure
portfolio/
├── index.html       # All pages and content structure
├── styles.css       # Complete design system & responsive styles
└── script.js        # Navigation, animations, particles, form logic
Three files. No build tools. No dependencies. No npm install. Just open index.html in a browser.

🛠️ Built With
• HTML5 — Semantic structure, accessibility-first markup
• CSS3 — Custom properties, Grid, Flexbox, animations, responsive design
• Vanilla JavaScript — No frameworks, no dependencies
• Google Fonts — Outfit (UI) + Fraunces (display headings)
• Canvas API — Particle network background
✨ Features
• Particle canvas background — Animated network of floating dots with connecting lines
• Typewriter effect — Role ticker cycles through different descriptions
• Animated skill bars — Smooth fill animations for each language/tool
• Page navigation — SPA-style section switching without page reloads
• Mobile drawer — Hamburger menu with slide-in navigation for small screens
• Contact form — Client-side validation with shake animation on error
• Reduced motion support — Respects prefers-reduced-motion system setting
• Dark theme — Deep indigo palette, easy on the eyes
• Fully responsive — Works on mobile, tablet, and desktop

git clone https://github.com/mdfaisal/portfolio.git

# Open in browser
cd portfolio
open index.html
Or just drag index.html into any browser window.
🔧 Customisation
Want to fork and make it yours? Here's what to change:
1. Your name & bio — index.html, inside .home-hero
2. Social links — Search for linkedin.com, github.com, mailto: in index.html
3. Projects — Update the .project-card blocks in the projects section
4. Skill levels — Change data-w values on .skill-fill elements (0–100)
5. Colours — All colours are CSS variables in styles.css under :root
